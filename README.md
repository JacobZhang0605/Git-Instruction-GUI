## About
A simple GUI tool for git and github learners, especially for those who are confused with the process of uploading files

## Run
### Run from website  
```bash
https://JacobZhang0605.github.io/Git-Instruction-GUI/
```
### Run from local (Linux)
```bash
cd <path>
git clone https://github.com/JacobZhang0605/Git-Instruction-GUI.git
cd Git-Instruction-GUI
xdg-open index.html
```
